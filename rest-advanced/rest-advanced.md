# REST advanced
{: .no_toc }

---

We may engage a new analysis request which REST is unable to handle. It is possible to modify/add processes
to REST source code, or to develop a new project based on REST. The project can either be a program running 
separately, or a library added into REST libraries.

In this section, you will find

- [REST processes development](https://rest-for-physics.github.io/rest-advanced/process-development.html) To be reviewed
- [Metadata class development](https://rest-for-physics.github.io/rest-advanced/metadata-development.html) To be written
- [Adding a new class](https://rest-for-physics.github.io/rest-advanced/adding-class.html)
- [Adding a new library](https://rest-for-physics.github.io/rest-advanced/adding-library.html) To be written
- [Adding a new package](https://rest-for-physics.github.io/rest-advanced/adding-package.html) To be updated
- [Generating a new official release](https://rest-for-physics.github.io/rest-advanced/new-release.html)
